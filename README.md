# 人生挂机游戏 Web 原型

这是根据《人生挂机游戏-第一期开发需求清单》实现的静态 Web 原型。

## 打开方式

直接打开 `index.html` 即可运行。

## 已实现

- 少年期、大学期、职场前期三阶段推进
- 点击已解锁技能即可开始挂机训练
- 技能卡显示经验读条和技能 CD 读条，CD 完成后自动结算技能经验
- 属性、资源、技能经验与升级结算
- 技能解锁条件
- 技能学习加速关系
- 随机事件、选择后果和事件历史
- 社交场景、NPC 友好度与关系事件
- 背包道具获取与统计
- 本地存档与离线收益
- 职业申请与成就系统

## 存档

存档保存在浏览器 `localStorage` 中，重开会清空当前本地存档。
