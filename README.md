# 人生挂机游戏 Web 原型

这是根据《人生挂机游戏-第一期开发需求清单》实现的静态 Web 原型。

## 打开方式

直接打开 `index.html` 即可运行。

## 已实现

- 少年期、大学期、职场前期三阶段推进
- 点击已解锁技能即可开始挂机训练
- 技能卡显示经验读条和技能 CD 读条，CD 完成后自动结算技能经验
- 属性、资源、技能经验与升级结算
- 未发现技能隐藏、生活经验发现与阶段性主动训练
- 技能学习加速关系
- 全技能 1–99 级成长曲线与旧存档等级迁移
- 通用事件内容包、技能/社交等触发来源、选择后果和事件历史
- 社交场景、NPC 友好度与关系事件
- 背包道具获取与统计
- 体育技能提高体力上限
- 本地存档与离线收益
- 职业申请与成就系统

## 存档

存档保存在浏览器 `localStorage` 中，重新打开页面会继续当前进度。

## 编写事件

新事件写在 `content-events.js` 的事件包中，格式和支持的触发条件、效果类型见 [事件编写指南](./事件编写指南.md)。

修改内容后运行：

```bash
node smoke-test.js
node balance-test.js
```

测试会同时检查事件 ID、技能/NPC/道具引用、核心挂机、社交发现和体力上限流程，并验证高效率路线下全技能达到 99 级仍不少于 100 小时。
